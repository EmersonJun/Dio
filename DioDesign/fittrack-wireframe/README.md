# FitTrack — Wireframe One Page

Wireframe de média fidelidade para uma landing page de um aplicativo de organização de treinos. O projeto foi criado como entrega de desafio de UX/UI, com foco em hierarquia visual, clareza das ações e organização do conteúdo.

## Objetivo

Apresentar o FitTrack e incentivar visitantes a conhecer o aplicativo ou criar uma conta. A página é uma proposta conceitual: não existe cadastro funcional nem integração com backend.

## Público-alvo

Pessoas que treinam em academia e querem registrar exercícios, cargas e acompanhar sua evolução sem depender de anotações dispersas.

## Estrutura da página

1. **Cabeçalho:** marca e navegação para Recursos, Como funciona e Entrar.
2. **Hero:** mensagem principal, explicação curta, CTA e área reservada para uma prévia do aplicativo.
3. **Benefícios:** dois blocos com os principais usos — registrar treinos e acompanhar evolução.
4. **Chamada final:** reforça o benefício e apresenta uma segunda ação.

## Decisões de UX e usabilidade

- **Hierarquia visual:** título principal e CTA aparecem primeiro para facilitar a identificação do propósito da página.
- **Lei de Hick:** navegação curta e poucas ações principais reduzem a complexidade da escolha.
- **Lei de Fitts:** CTAs têm área ampla e espaçamento para facilitar o clique/toque.
- **Lei de Jakob:** usa padrões conhecidos de landing pages, como marca no topo, navegação e chamada principal.
- **Heurísticas de Nielsen:** conteúdo com linguagem direta, consistência entre botões e navegação previsível. Em uma implementação funcional, ações de cadastro e navegação devem fornecer feedback claro.

Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Ferramentas

HTML, CSS, Figma (opcional para recriar/editar visualmente) e GitHub.

## Observação

Este projeto é um wireframe de média fidelidade, não um produto final. Textos, componentes e disposição podem ser ajustados após testes com usuários e feedback.
