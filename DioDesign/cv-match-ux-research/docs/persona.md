# Persona — Lucas Martins

> Persona hipotética para orientar o protótipo. Validar ou ajustar com entrevistas reais.

**Perfil:** candidato em início de carreira em tecnologia  
**Idade fictícia:** 23 anos

## Contexto
Busca uma oportunidade como desenvolvedor júnior. Tem conhecimentos de estudos e projetos pessoais, mas pouca experiência profissional.

## Objetivo
Encontrar vagas adequadas e apresentar habilidades com clareza.

## Necessidades
- Compreender requisitos atendidos.
- Identificar habilidades a destacar.
- Melhorar currículo sem inventar experiências.
- Receber orientações simples e objetivas.

## Frustrações
- Vagas com muitos requisitos técnicos.
- Não saber quais habilidades são prioritárias.
- Poucas explicações sobre compatibilidade.
- Dificuldade para apresentar projetos pessoais.

## Comportamento
Pesquisa vagas, compara requisitos e usa um currículo-base para candidaturas.

**Frase fictícia:** “Quero saber o que realmente preciso melhorar no meu currículo antes de enviar para uma vaga.”

## Oportunidade para o CV Match
Mostrar requisitos encontrados e não identificados, explicar os resultados e sugerir melhorias apoiadas nas experiências reais do candidato.
