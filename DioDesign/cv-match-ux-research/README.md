# UX Research — CV Match

Projeto demonstrativo de UX Research para investigar como candidatos analisam e adaptam currículos a vagas.

> **Importante:** entrevistas, falas, persona e padrões de resultados deste pacote são exemplos fictícios. Substitua-os por dados de entrevistas reais antes de apresentar o projeto como pesquisa realizada.

## Conteúdo
- `docs/plano-de-pesquisa.md` — problema, objetivos, hipóteses, método e cronograma
- `docs/roteiro-de-entrevista.md` — roteiro de entrevista semiestruturada
- `docs/mapa-de-afinidades.md` — agrupamento demonstrativo de observações
- `docs/persona.md` — persona hipotética

## Descrição para entrega na DIO
Projeto de UX Research desenvolvido para investigar as dificuldades de candidatos durante a análise e adaptação de currículos a vagas de emprego. Apresenta plano de pesquisa, roteiro de entrevistas, mapa de afinidades, persona, jornada do usuário e recomendações para o CV Match, ferramenta de análise de compatibilidade entre currículos e oportunidades.
